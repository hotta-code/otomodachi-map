# ほっぺくんのおともだちMAP

ほのぼのしたカフェの世界観で、ほっぺくんのおともだちがいる都道府県・海外の国や地域を記録するWebマップです。

## 主な機能
- 背景透過した「ほっぺくん」キャラクターを大きく表示
- 実際の47都道府県地図
- 都道府県別のおともだち数
- 8エリア別の色分け・合計
- 海外のおともだち登録
- 日本合計 / 海外合計 / 総合計
- PNG画像保存
- PDF保存
- MAP共有
- スクショ表示
- スマホ対応
- 忍者MAPとは保存データを完全分離

## GitHub Pages 公開
1. ZIPを展開
2. 中身をすべて `otomodachi-map` リポジトリ直下へアップロード
3. Commit changes
4. Settings → Pages
5. Deploy from a branch
6. `main` / `/(root)` → Save
